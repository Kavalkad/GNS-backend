# GNS-backend
## Описание

GNS-backend – это полноценный REST API бэкенд для управления сетью киберклубов. Проект построен на ASP.NET Core 10 с разделением прав доступа по ролям.

Поддерживаются 4 типа пользователей:
- User – может делать заказы, получать список клубов, игровых мест и т.д.
- Admin – все действия User'a + может получать заказы конкретного юзера, обновлять статус заказа
- Manager – все действия Admin'a + может давать штрафы и бонусы сотрудникам своего клуба
- Owner – все действия User'a + может совершать бОльшую часть CRUD операций с основными сущностями(клубы, игр. места, работники и т.д.)

## Основной функционал
- Авторизация и аутентификация на основе JWT и RefreshToken'а
- Фильтр Блума
- CRUD операции со всеми сущностями
- Заказы игрового места на определённый временной слот, получение недоступных для заказа временных слотов
- Ограничение доступов 

## Технологический стек

- .NET 10 – основной фреймворк
- Entity Framework Core 10 + SQLite – работа с данными
- JWT Bearer Authentication – аутентификация и авторизация
- BCrypt – хеширование паролей
- Swagger / Swashbuckle – документация API
- BackgroundServices + Cronos – фоновые задачи 

## Структура проекта

- Data/ –  DbContext, сущности, репозитории, конфигурации
- Endpoints/ – API эндпоинты по ролям 
- Services/ — бизнес-логика
- Dto/ — data transfer objects
- Contracts/ — интерфейсы и модели контрактов получения данных
- Enums/ — перечисления ролей, статусов заказа, оборудования игровых мест
- BackgroundServices/ — фоновые службы
- Middleware/ — кастомное middleware
- Migrations/ — миграции базы данных

## Запуск проекта
### Требования

- [.NET 10 SDK]
- EF Core 10

### База данных
Проект использует SQLite (файл app.db в корне). База данных создаётся автоматически при первом запуске (`Database.EnsureCreated()`).
### Как запустить
`dotnet run`
